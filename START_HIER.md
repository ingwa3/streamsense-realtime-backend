# Projektstart

Die vollständige technische Anleitung steht in `README.md`.

Für einen schnellen lokalen Funktions- und Lasttest stehen zwei Starter bereit:

- Windows: `ABSCHLUSS_TEST_WINDOWS.bat`
- macOS/Linux: `ABSCHLUSS_TEST_MAC_LINUX.command`

Beide starten `scripts/abschluss_test.py`. Das Skript erzeugt standardmäßig genau 1.000.000 Ereignisse und schreibt die lokalen Ergebnisse nach `docs/TESTERGEBNISSE_AUTOMATISCH.md` und `docs/TESTERGEBNISSE_AUTOMATISCH.json`.
